# DeployGuard — Local Development Harness
# Run `make help` for available targets

.PHONY: help install dev test lint format health clean

# Default target
.DEFAULT_GOAL := help

# Variables
PORT ?= 8000
PYTHON := python
UV := uv
SRC := src
TESTS := tests

help: ## Show available make targets
	@grep -E '^[a-zA-Z_-]+:.*?## .*$$' $(MAKEFILE_LIST) | sort | awk 'BEGIN {FS = ":.*?## "}; {printf "\033[36m%-20s\033[0m %s\n", $$1, $$2}'

install: ## Install all dependencies (runtime + dev) via uv
	$(UV) pip install -e ".[dev]"

dev: ## Start the FastAPI development server on PORT (default: 8000)
	@echo "Starting DeployGuard on http://localhost:$(PORT)"
	@echo "API docs at http://localhost:$(PORT)/docs"
	$(UV) run uvicorn deployguard.main:app --host 0.0.0.0 --port $(PORT) --reload

test: ## Run all pytest tests
	$(UV) run pytest $(TESTS) -v --tb=short

test-unit: ## Run only unit tests (fast, no integration)
	$(UV) run pytest $(TESTS) -v --tb=short -m "not integration"

lint: ## Run ruff linter
	$(UV) run ruff check $(SRC) $(TESTS)

format: ## Format code with ruff
	$(UV) run ruff format $(SRC) $(TESTS)

typecheck: ## Run mypy type checker
	$(UV) run mypy $(SRC)

health: ## Hit the /health endpoint (server must be running)
	@curl -s http://localhost:$(PORT)/health | python -m json.tool

clean: ## Remove Python caches and build artifacts
	find . -type d -name __pycache__ -exec rm -rf {} + 2>/dev/null || true
	find . -name "*.pyc" -delete 2>/dev/null || true
	rm -rf .pytest_cache .mypy_cache .ruff_cache dist build *.egg-info
```

# DeployGuard

> Fortified Enterprise Fleet for Safe CI/CD Operations

DeployGuard is a governed multi-agent CI/CD safety system that detects production anomalies after deployment, investigates failures using historical incident memory, makes policy-governed rollback decisions, executes remediation, and generates complete auditable postmortems.

**"DeployGuard doesn't just detect failed deployments. It understands, decides, acts, verifies, and explains."**

---

## Agent Fleet

| Agent | Role | Risk |
|-------|------|------|
| Deploy Monitor Agent | Monitors post-deployment metrics, detects anomalies | MEDIUM |
| Decision Agent | Reasons over evidence + history, determines action | HIGH |
| Incident Memory Agent | Stores/retrieves historical incident context | MEDIUM |
| Rollback Agent | Executes authorized rollbacks via Cloud Deploy | CRITICAL |
| Postmortem Agent | Generates auditable postmortem documents | LOW |

---

## Architecture

```
                    Deploy Monitor Agent
                           │
                           ▼
                    Cloud Monitoring (Stub → Real)
                           │
                    Anomaly detected?
                      /           \
                    NO            YES
                                   │
                             Decision Agent
                                   │
                             Incident Memory Agent
                             (Firestore Stub → Real)
                                   │
                             ┌─────┼─────┐
                             ▼           ▼
                         Rollback    Alert/Page
                         Agent
                             │
                         Cloud Deploy (Stub → Real)
                             │
                         Recovery Verification
                             │
                         Postmortem Agent
```

All agents operate through the **Agent Gateway** which enforces:
- Agent identity (IAM service accounts in production)
- Permission checks (least-privilege per agent)
- Policy evaluation (confidence thresholds, deployment age, environment)

**Model Armor** screens production logs for prompt injection before they reach any agent.
