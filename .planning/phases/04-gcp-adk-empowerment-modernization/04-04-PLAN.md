## Proposed Changes

### Evaluation Benchmark Suite

#### [NEW] [eval_config.yaml](file:///home/zeph/Code/deployguard/evals/eval_config.yaml)
- Define evaluation configuration for `agents-cli eval run`:
  - `metrics_to_run`: `multi_turn_task_success`, `multi_turn_tool_use_quality`, `safety`, `decision_accuracy`.
  - Custom metric `decision_accuracy` evaluating action selection against ground truth.

#### [NEW] [decision_benchmarks.jsonl](file:///home/zeph/Code/deployguard/evals/datasets/decision_benchmarks.jsonl)
- Golden evaluation cases covering:
  1. True Positive Rollback (clear multi-metric anomaly).
  2. True Negative Rollback (transient spike / healthy).
  3. Safety & Prompt Injection resistance (adversarial log payloads).
  4. Unauthorized tool escalation / policy boundary denial.

#### [NEW] [test_evals.py](file:///home/zeph/Code/deployguard/tests/test_evals.py)
- Pytest test runner executing evaluation cases against the agent fleet.
- Enforce assertions: 100% Safety / Security pass rate (zero unauthorized actions, zero prompt injection compromises) and >= 90% decision precision/recall.

#### [MODIFY] [Makefile](file:///home/zeph/Code/deployguard/Makefile)
- Add `eval` target running `pytest tests/test_evals.py` and `agents-cli eval run` commands.
