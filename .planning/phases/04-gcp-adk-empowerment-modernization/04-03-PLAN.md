# Plan 04-03 — Google Cloud Native Telemetry & Service Connectors

**Phase**: 04 — Google Cloud Platform & ADK Fleet Modernization
**Plan**: 04-03
**Wave**: 2
**Depends on**: 04-01, 04-02
**Objective**: Build live Google Cloud service connectors for Cloud Monitoring (PromQL/ListTimeSeries), Cloud Logging (LQL), and Cloud Deploy with seamless stub fallback and IAM mappings.

## Proposed Changes

### Cloud Connectors

#### [NEW] [monitoring_client.py](file:///home/zeph/Code/deployguard/src/deployguard/cloud/monitoring_client.py)
- Implement `LiveCloudMonitoringClient` using `google-cloud-monitoring`.
- Construct valid `projects.timeSeries.list` filters and PromQL aggregations across the 7 deployment metric dimensions.

#### [NEW] [logging_client.py](file:///home/zeph/Code/deployguard/src/deployguard/cloud/logging_client.py)
- Implement `LiveCloudLoggingClient` using `google-cloud-logging`.
- Build structured LQL filters (`resource.type="cloud_run_revision" severity>=WARNING timestamp>="..."`).
- Run retrieved logs immediately through `LogSanitizer` prior to returning.

#### [NEW] [deploy_client.py](file:///home/zeph/Code/deployguard/src/deployguard/cloud/deploy_client.py)
- Implement `LiveCloudDeployClient` using `google-cloud-deploy` for target rollback execution.
- Declaratively bind agent identities to GCP Service Accounts (`deployguard-rollback@<project>.iam.gserviceaccount.com` with `roles/clouddeploy.releaser`).

#### [NEW] [factory.py](file:///home/zeph/Code/deployguard/src/deployguard/cloud/factory.py)
- Implement connector factory with ADC discovery (`google.auth.default()`).
- Seamlessly route to live clients when configured or fall back to `MockMonitoring`, `MockLogging`, and `MockCloudDeploy` stubs when `DEPLOYGUARD_MOCK_GCP=true` or credentials are absent.
