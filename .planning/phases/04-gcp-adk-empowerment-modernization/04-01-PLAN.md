# Plan 04-01 — Google ADK Fleet Architecture & Gateway Tool Interceptor

**Phase**: 04 — Google Cloud Platform & ADK Fleet Modernization
**Plan**: 04-01
**Wave**: 1
**Depends on**: None
**Objective**: Modernize the agent fleet to native Google ADK Agent architectures and implement Gateway-wrapped ADK function tools.

## Proposed Changes

### Agents & Tools

#### [NEW] [adk_tools.py](file:///home/zeph/Code/deployguard/src/deployguard/agents/adk_tools.py)
- Implement `@gateway_tool` decorator that wraps standard Google ADK function tools.
- Decorator verifies calling agent ID against `AgentRegistry`, verifies IAM role permissions, and passes arguments through `LogSanitizer`.
- Define ADK function tools with standard docstrings and type annotations:
  - `query_monitoring_metrics`: queries metric telemetry for deployment window.
  - `fetch_historical_incidents`: queries incident memory with vector similarity and metadata filters.
  - `request_deployment_rollback`: requests deployment rollback (requires `deployment.rollback` permission).
  - `record_incident`: writes an incident postmortem/summary to memory.

#### [MODIFY] [base.py](file:///home/zeph/Code/deployguard/src/deployguard/agents/base.py)
- Refactor `BaseAgent` and fleet agents to wrap Google ADK `Agent` / `LlmAgent` primitives.
- Configure default Gemini models (`gemini-2.5-flash` / `gemini-2.5-pro`) with configurable settings.
- Implement ADK lifecycle callbacks (`before_tool_callback`, `after_tool_callback`).

#### [NEW] [agent.yaml](file:///home/zeph/Code/deployguard/agent.yaml)
- Declarative agent configuration manifest for Google `agents-cli` onboarding, local playground, and evaluation compatibility.

### Tests
