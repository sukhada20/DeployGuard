# Plan 06-02 — Dashboard Backend APIs & Real-Time SSE Broadcaster

**Phase**: 06 — Postmortem Generation & Operator Dashboard
**Plan**: 06-02
**Wave**: 1
**Depends on**: None
**Objective**: Implement FastAPI REST endpoints for dashboard overview, telemetry metrics, decision traces, postmortems, and agent registry, along with a live Server-Sent Events (SSE) broadcaster endpoint (`/api/v1/events/stream`) with publishing hooks for agent lifecycles, metric ticks, and anomaly alerts.

## Proposed Changes

### Dashboard Backend APIs & SSE Broadcaster

#### [NEW] [events.py](file:///home/zeph/Code/deployguard/src/deployguard/api/events.py)
- Implement `AsyncEventBroadcaster` singleton managing active client subscriptions via `asyncio.Queue`.
- Define helper `broadcast_event(event_type: str, data: dict[str, Any])` callable across agent lifecycle hooks and simulator.
- Implement SSE route: `GET /api/v1/events/stream` returning `text/event-stream` with keep-alive heartbeat and event formatting (`event: <type>\ndata: <json>\n\n`).

#### [NEW] [dashboard.py](file:///home/zeph/Code/deployguard/src/deployguard/api/dashboard.py)
- `GET /api/v1/dashboard/overview`: Returns current cluster status, active deployment state, monitored services count, and live incident statistics.
- `GET /api/v1/dashboard/metrics`: Returns 7-dimension baseline telemetry metrics, current post-deploy values, and anomaly delta percentages.

#### [NEW] [traces.py](file:///home/zeph/Code/deployguard/src/deployguard/api/traces.py)
- `GET /api/v1/traces`: List decision traces with filtering by service, decision outcome (`rollback`, `wait`, `alert`), and pagination.
- `GET /api/v1/traces/{trace_id}`: Retrieve full decision trace with policy evaluation breakdown and correlated OpenTelemetry span hierarchy.

#### [NEW] [postmortems.py](file:///home/zeph/Code/deployguard/src/deployguard/api/postmortems.py)
- `GET /api/v1/postmortems`: List generated postmortems with service, severity, resolution, and timestamp.
- `GET /api/v1/postmortems/{report_id}`: Return complete `PostmortemReport` object with rendered Markdown string.

#### [MODIFY] [main.py](file:///home/zeph/Code/deployguard/src/deployguard/main.py)
- Register all new routers (`dashboard_router`, `traces_router`, `postmortems_router`, `events_router`) under `/api/v1`.
- Initialize `AsyncEventBroadcaster` in application lifespan state.
