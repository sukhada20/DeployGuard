#### [NEW] [runner.py](file:///home/zeph/Code/deployguard/src/deployguard/demo/runner.py)
- `DemoRunner` class:
  - Supports `--interactive` (default, pauses on Enter), `--auto` (timed 1s delay), and `--ci` (fastest headless execution).
  - Generates isolated deployment ID (`f"deploy-demo-{int(time.time())}"`).
  - Initializes mock state and connects to FastAPI `AsyncEventBroadcaster` singleton when server is running.
  - Executes full 8-stage autonomous lifecycle:
    1. Deployment initiation (`checkout-service` `v2.4.0`)
    2. Metric failure injection (error rate +1150%, latency p95 +440%)
    3. Anomaly detection via `DeployMonitorAgent`
    4. Incident memory vector lookup via `IncidentMemoryAgent`
    5. Governed decisioning via `DecisionAgent` (Gemini + Model Armor + Policy Engine)
    6. Rollback execution via `RollbackAgent`
    7. Multi-step recovery verification via `DeployMonitorAgent`
    8. Postmortem synthesis & Firestore write via `PostmortemAgent`
  - Broadcasts SSE events at each stage for live browser dashboard synchronization.

#### [NEW] [clean.py](file:///home/zeph/Code/deployguard/src/deployguard/demo/clean.py)
- Reset utility to clear mock Firestore collections, reset state files, and purge demo logs.
