## Proposed Changes

### Integration Test Suites

#### [NEW] [test_e2e_pipeline.py](file:///home/zeph/Code/deployguard/tests/test_e2e_pipeline.py)
- Test `test_full_autonomous_deployment_lifecycle`:
  - Executes all 8 stages from initial deployment -> metric failure injection -> baseline anomaly detection -> incident memory lookup -> governed decision -> rollback execution -> recovery verification -> postmortem synthesis.
  - Asserts that `recovery_verdict == "recovered"`, `postmortem_report is not None`, and generated postmortem Markdown contains complete 5-whys RCA and timeline.
- Test `test_e2e_recovery_failure_handling`:
  - Injects persistent failure after rollback and asserts that recovery verification fails gracefully and records `failed_rollback` verdict in postmortem.
- Configure `@pytest.mark.live_gcp` for tests requiring live Google Cloud endpoints.

#### [NEW] [test_security_scenarios.py](file:///home/zeph/Code/deployguard/tests/test_security_scenarios.py)
- Test `test_gateway_unauthorized_action_denial`:
  - Asserts that `AgentGateway` denies unauthorized tool calls and emits DENIED trace.
- Test `test_prompt_injection_sanitization_defense`:
  - Asserts that malicious log payloads are neutralized by `LogSanitizer` without corrupting policy evaluations.
- Test `test_inactive_agent_call_rejection`:
  - Asserts that calls from disabled or unregistered agents are rejected immediately.
